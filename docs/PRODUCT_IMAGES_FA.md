# تصاویر سه محصول اصلی

تصاویر طراحی‌شده به محصولات اوره ۴۶٪، ABS و PM200/MDI وصل شده‌اند. همان تصویر در صفحه اصلی، فهرست محصولات و صفحه جزئیات نمایش داده می‌شود. فایل‌های PNG همراه پروژه در `static/images/products/` هستند و به انتقال دیتابیس یا پوشه media وابسته نیستند.

تصاویر برای نمایش نوع محصول طراحی شده‌اند؛ عکس یک محموله یا بسته‌بندی تأییدشده سازنده نیستند. اگر از پنل مدیریت تصویر واقعی محصول را آپلود کنی، عکس جدید اولویت دارد. پاک‌کردن فیلد تصویر، تصویر همراه پروژه را دوباره فعال می‌کند.

## به‌روزرسانی نصب فعلی

1. در ترمینالِ سرور Ctrl+C بزن.
2. بسته `TTA_Product_Images_Update.zip` را Extract کن.
3. فایل `APPLY_PRODUCT_IMAGES.cmd` را اجرا کن.
4. مسیر پیش‌فرض پروژه `D:\Django\ttagroups4\django-industrial-catalog` است. فایل فرمان ابتدا پایتون محیط مجازی همین پروژه را بررسی می‌کند و در صورت نبودن آن، از محیط نصب‌شده در `ttagroups3` استفاده می‌کند.
5. پس از پیام `TTA PRODUCT IMAGES UPDATE COMPLETED`، سایت را دوباره اجرا کن.

اگر متغیر پایتون را طبق راهنمای قبلی در همان ترمینال تنظیم کرده‌ای:

```powershell
& $projectPython manage.py runserver 8001
```

سپس `http://127.0.0.1:8001/fa/` را با Ctrl+F5 تازه‌سازی کن. ساخت مجدد محیط مجازی، migrate یا بارگذاری دوباره محصولات برای این اصلاح لازم نیست. فایل‌های جایگزین‌شده در پوشه موقت ویندوز بک‌آپ می‌شوند؛ مسیر بک‌آپ در خروجی نوشته می‌شود. این به‌روزرسانی دیتابیس، حساب‌ها و آپلودها را تغییر نمی‌دهد.

برای مسیر متفاوت، در PowerShell پوشه استخراج‌شده اجرا کن:

```powershell
.\APPLY_PRODUCT_IMAGES.cmd "D:\path-to-project\django-industrial-catalog"
```

آرگومان دوم اختیاری، مسیر پایتون محیط مجازی است. منطق اسکریپت در محیط آزمایشی اجرا شده است؛ اجرای فایل CMD روی ویندوز با مشاهده خروجی آن تأیید می‌شود.

## نصب جدید و انتشار

نسخه کامل ZIP همین تصاویر و کد اتصالشان را دارد. راه‌اندازی نصب جدید طبق README است. برای GitHub فایل‌های داخل پوشه پروژه را commit کن؛ تصاویر ثابت هم همراه آن‌ها وارد مخزن می‌شوند. آپلودهای media همچنان در Git نادیده گرفته می‌شوند.

روی هاست، پیش از restart برنامه، با پایتون محیط مجازی همان هاست اجرا کن:

```bash
python manage.py collectstatic --noinput
```

وب‌سرور باید مسیر STATIC_ROOT را در `/static/` سرو کند. اطلاعات اختصاصی cPanel، نسخه Python، Application root و محل STATIC_ROOT باید از تنظیمات همان هاست تعیین شوند؛ این بسته به‌صورت خودکار سایت آنلاین را تغییر نمی‌دهد.
